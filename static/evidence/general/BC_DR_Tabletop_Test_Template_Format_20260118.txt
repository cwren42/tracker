Scenario: 

A ransomware attack has occurred on Friday afternoon at 3:00 PM. Multiple employees report encrypted files with ransom notes on their screens. The file server (\\FILESERVER\Shared) has all files encrypted. Twelve workstations show ransom notes and encrypted files. One Azure VM (WEB-PROD-02) is encrypted and offline. The ransom note demands $50,000 in Bitcoin within 72 hours and threatens to publish data if not paid. It is unknown how attackers gained access or if backups are affected.

Summary of Learnings from Test: 

* **STRENGTHS:** Team understood roles and responsibilities clearly. Communication tree worked effectively. Backup systems were robust and accessible. Executive decision-making was rapid and clear (no ransom payment). Cloud backups provided critical protection. Customer communication approach was well-structured.

* **TECHNICAL GAPS:** Need immutable Azure Backup vaults (HIGH priority). Need automated workstation imaging solution (MEDIUM priority). Need MFA on file server access to prevent lateral movement (HIGH priority).

* **PROCESS GAPS:** Need pre-written breach notification templates approved by legal (HIGH priority). Need formal media communication plan and spokesperson training (MEDIUM priority). Need more spare laptop inventory (LOW priority - 8 is adequate for most scenarios).

* **OVERALL ASSESSMENT:** Team would respond effectively to a real ransomware incident. All critical systems recoverable within RTO targets. High confidence in disaster recovery capability. Exercise rated 4.6/5.0 by participants.
