SYSTEM OVERVIEW
================================================================================

System Name: Customer Lead Capture System
Purpose: Collect customer contact information via website for sales team
Data Classification: Public/Low Sensitivity (contact information only)
System Boundary: Cloud-based CRM system (Sales team access only)

================================================================================
DATA FLOW DESCRIPTION
================================================================================

FLOW 1: Customer to Cloud Storage
--------------------------------------------------------------------------------

Source: Data from Customer A (Website visitors)
Destination: Cloud Storage (Sales only)
Data Type: Customer name and contact information
Transport: HTTPS (encrypted in transit)

Data Elements Collected:
- Customer Name (First Name, Last Name)
- Email Address
- Phone Number (optional)
- Company Name (optional)
- Contact Message/Inquiry

Collection Method:
1) Data comes in via a website form
2) User inputs their name and contact information
3) Form submission triggers HTTPS POST request
4) Data transmitted securely to cloud CRM

Security Controls:
✓ HTTPS encryption (TLS 1.2 or higher)
✓ Form validation (prevent injection attacks)
✓ Rate limiting (prevent abuse)
✓ CAPTCHA protection (prevent bot submissions)

================================================================================
DATA STORAGE
================================================================================

Storage Location: Cloud-based CRM System
Cloud Provider: [CRM Provider Name - e.g., Salesforce, HubSpot, etc.]
Storage Region: United States
Access Control: Sales Team Only

Data Retention:
- Active leads: Retained indefinitely
- Closed leads: Retained per retention policy (7 years)
- Deleted upon customer request (GDPR/privacy compliance)

Privacy Controls:
✓ No private/sensitive information stored
✓ No PII beyond basic contact information
✓ No financial information
✓ No health information
✓ No authentication credentials

Access Restrictions:
- Sales Team: Full access (read/write)
- Marketing Team: Read-only access (if approved)
- IT Admin: Administrative access (as needed)
- All other employees: No access

================================================================================
DATA FLOW ANSWERS
================================================================================

Q1: How does data enter the system?
A1: Data comes in via a website and inputs the users name and contact 
    information through a web form.

Q2: Where is the data stored?
A2: This goes to a cloud base CRM. No private info is stored on here.
    Only basic contact information (name, email, phone, inquiry message).

Q3: Does data flow to other systems?
A3: No Flow - Data stays within the cloud CRM system. No integration with
    other systems at this time.

Q4: What network security is required?
A4: No need for firewall - This is a cloud-to-cloud connection. The CRM
    system is accessed via HTTPS over the internet. Cloud provider manages
    their own network security/firewalls.

Q5: Who has access to this data?
A5: Sales Team - Only the sales team has access to the customer lead data
    stored in the cloud CRM system.

SECURITY CONTROLS
================================================================================

TECHNICAL CONTROLS:

Data in Transit:
✓ HTTPS/TLS encryption (website to CRM)
✓ Certificate validation
✓ Strong cipher suites only
✓ No plaintext transmission

Data at Rest:
✓ Cloud provider encryption (AES-256)
✓ Encrypted database storage
✓ Encrypted backups

Access Control:
✓ Cloud CRM authentication (username/password)
✓ Multi-factor authentication (MFA) required
✓ Role-based access control (RBAC)
✓ Principle of least privilege

Monitoring:
✓ Access logging enabled
✓ Audit trail of all data access
✓ Alerts for suspicious activity
✓ Quarterly access reviews

ADMINISTRATIVE CONTROLS:

✓ Privacy policy published on website
✓ Data retention policy defined
✓ Access provisioning/deprovisioning procedures
✓ Employee training on data handling
✓ Vendor security assessment (CRM provider)

PHYSICAL CONTROLS:

✓ Cloud provider data center security
✓ No physical access by Cirque employees
✓ Cloud provider SOC 2 certification verified

================================================================================
RISK ASSESSMENT
================================================================================

RISKS IDENTIFIED:

1. Unauthorized Access to CRM
   Likelihood: LOW
   Impact: MEDIUM
   Mitigation: MFA required, strong passwords, access reviews

2. Data Breach at Cloud Provider
   Likelihood: LOW
   Impact: MEDIUM
   Mitigation: Vendor due diligence, SOC 2 certified provider, 
               limited sensitive data stored

3. Website Form Abuse/Spam
   Likelihood: MEDIUM
   Impact: LOW
   Mitigation: CAPTCHA, rate limiting, form validation

4. Insider Threat (Sales Team)
   Likelihood: LOW
   Impact: LOW
   Mitigation: Access logging, acceptable use policy, background checks

5. Privacy Regulation Non-Compliance
   Likelihood: LOW
   Impact: HIGH
   Mitigation: Privacy policy, consent mechanism, deletion procedures

OVERALL RISK LEVEL: LOW
Justification: Limited sensitive data, strong security controls in place,
               reputable cloud provider, clear access restrictions
