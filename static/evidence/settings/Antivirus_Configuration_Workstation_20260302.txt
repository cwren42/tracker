compliance requirements to protect against viruses and malicious software.

================================================================================
ANTIVIRUS CONFIGURATION BY PLATFORM
================================================================================

WINDOWS COMPUTERS (Laptops and Desktops)
--------------------------------------------------------------------------------
Required: YES - Antivirus protection is MANDATORY for all Windows workstations

Solution: Windows Defender (Native)
- Microsoft Windows Defender is the approved antivirus solution
- Pre-installed with Windows 10/11 operating systems
- Meets enterprise security requirements when properly configured
- No additional third-party antivirus required

Configuration Requirements:
✓ Real-time protection: ENABLED
✓ Cloud-delivered protection: ENABLED
✓ Automatic sample submission: ENABLED
✓ Tamper protection: ENABLED
✓ Controlled folder access: ENABLED (for sensitive data)
✓ Automatic definition updates: ENABLED (daily minimum)
✓ Quick scan schedule: Weekly
✓ Full scan schedule: Monthly

Windows Defender Features Enabled:
- Virus & threat protection
- Account protection
- Firewall & network protection
- App & browser control
- Device security
- Core isolation (memory integrity)

Management:
- Managed through Microsoft Intune/Endpoint Manager
- Centralized monitoring via Microsoft 365 Security Center
- Automatic updates deployed via Windows Update
- Security alerts routed to IT Security team

Compliance:
✓ All Windows workstations have Defender enabled
✓ Regular compliance scans verify coverage
✓ Non-compliant devices flagged and remediated
✓ Users cannot permanently disable protection


MACOS COMPUTERS (MacBooks and iMacs)
--------------------------------------------------------------------------------
Required: NO - Antivirus is not required for macOS workstations

Rationale:
- macOS has robust built-in security features (XProtect, Gatekeeper)
- Lower malware threat landscape compared to Windows
- System Integrity Protection (SIP) prevents system file modification
- Regular security updates from Apple provide protection

Recommended Security Measures (IMPLEMENTED):
✓ Full disk encryption (FileVault 2): ENABLED on all Macs
✓ Gatekeeper: ENABLED (allows only signed applications)
✓ XProtect: ENABLED (Apple's malware detection)
✓ Automatic software updates: ENABLED
✓ Firewall: ENABLED
✓ Remote wipe capability: ENABLED via MDM

Optional Enhancement:
- JamF (or similar MDM) used for device management and encryption enforcement
- Provides centralized control and compliance reporting
- Ensures FileVault encryption is enabled organization-wide
- Remote wipe and device tracking capabilities

Management:
- Enrolled in Mobile Device Management (MDM) system
- Disk encryption verified through MDM compliance checks
- Operating system updates managed centrally
- Security posture monitored continuously

Compliance:
✓ All macOS devices enrolled in MDM
✓ 100% disk encryption coverage verified
✓ Security updates applied within 30 days of release
✓ Compliance reports generated quarterly


LINUX COMPUTERS (Ubuntu, Fedora, etc.)
--------------------------------------------------------------------------------
Required: NO - Antivirus is not required for Linux workstations

Rationale:
- Linux architecture provides inherent security advantages
- Permission-based system limits malware spread
- Minimal malware targeting Linux desktop systems
- Regular security updates provide adequate protection

Recommended Security Measures (IMPLEMENTED):
✓ Operating system hardening: APPLIED
✓ Regular security updates: ENABLED (automatic)
✓ UFW/iptables firewall: ENABLED
✓ SELinux/AppArmor: ENABLED (where applicable)
✓ Minimal installed packages (reduced attack surface)
✓ User accounts follow least privilege principle

Optional Antivirus Solution (Available):
- ClamAV (open-source antivirus)
- Free and lightweight solution
- Easy to install and configure
- Suitable for users who prefer additional protection
- Not mandatory but supported if requested

Installation (Optional):
  sudo apt-get install clamav clamav-daemon
  sudo freshclam  # Update virus definitions
  sudo systemctl enable clamav-freshclam
  sudo systemctl start clamav-daemon

Management:
- Linux systems managed through standard IT support
- Security updates applied via package managers
- Configuration management via Ansible/Salt (as applicable)
- User education on secure computing practices

Compliance:
✓ All Linux workstations receive regular security updates
✓ System hardening applied consistently
✓ Firewall enabled and configured properly
✓ Users trained on Linux security best practices

================================================================================
INCIDENT RESPONSE
================================================================================

Malware Detection Procedure:
1. User notices suspicious behavior or receives security alert
2. User immediately reports to IT Support (support@cirque.com)
3. IT isolates affected workstation from network
4. Full antivirus scan performed
5. Malware removed or system reimaged if necessary
6. Security team investigates infection source
7. Additional protections implemented if vulnerability identified
8. Incident documented and reported to management
9. User receives additional security training if applicable

Escalation Path:
- Level 1: IT Support (initial response)
- Level 2: IT Security Team (investigation)
- Level 3: CISO (significant incidents)
- Management notification for data breach potential
