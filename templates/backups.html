Proxmox API Token Setup Instructions

Run these commands on any Proxmox node (as root or via the PVE shell). This creates a read-only API token that the tracker uses — it cannot make any changes to Proxmox.

1 Create the monitoring user
pveum user add monitoring@pve --comment "Tracker read-only"
2 Create a read-only role
pveum role add PVEReadOnly \
  --privs "Datastore.Audit,Sys.Audit,VM.Audit"
Skip this step if you already have PVEAuditor — use that instead.
3 Assign the role at root level
pveum acl modify / \
  --user monitoring@pve \
  --role PVEReadOnly
4 Generate the API token
pveum user token add monitoring@pve tracker \
  --privsep 0
Copy the Token ID (monitoring@pve!tracker) and the Secret UUID shown — the secret is only displayed once.
5 Verify the token works
curl -sk \
  -H "Authorization: PVEAPIToken=monitoring@pve!tracker=<your-secret-uuid>" \
  https://<node-ip>:8006/api2/json/nodes \
  | python3 -m json.tool
You should see a JSON list of your cluster nodes. If you get 401, double-check the secret UUID.
6 Enter credentials in Settings

Go to Settings → Proxmox and enter:

  • Cluster Host — IP or hostname of any cluster node (e.g. 10.10.1.10)
  • Token ID — monitoring@pve!tracker
  • Token Secret — the UUID shown in step 4
  • Optionally repeat steps 1–4 on the Bespin backup server and fill in the Backup Server section
