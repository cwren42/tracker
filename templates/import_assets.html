CSV Format Instructions

Your CSV file must include the following columns:

  • Asset Tag - Required, must be unique
  • Name - Required
  • Category - Required (Laptop, Desktop, Monitor, etc.)
  • Manufacturer - Optional
  • Model - Optional
  • Serial Number - Optional
  • Purchase Date - Optional (Format: YYYY-MM-DD)
  • Purchase Cost - Optional (Numbers only)
  • Warranty Expiry - Optional (Format: YYYY-MM-DD)
  • Status - Optional (Available, In Use, In Repair, Retired)
  • Location - Optional
  • Assigned To - Optional (Employee name - not currently used in import)
  • Notes - Optional
Note: You can export existing assets to see the correct CSV format.
