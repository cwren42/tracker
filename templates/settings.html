Cirque RMM Agent — One-Click Deploy

Deploy the RMM agent to any Windows endpoint. No parameters, no tokens to copy — just double-click the installer.

Deploy Steps
  1. Download CirqueRMM.exe from the button below.
  2. Copy it to the target Windows machine.
  3. Double-click it and accept the UAC prompt.
  4. The agent installs, auto-enrolls, and the CirqueRMM service starts — done.
Download .exe Download .msi Download .bat Download .ps1
  • .exe — Double-click, accept UAC. NSIS installer, bundles everything, works offline.
  • .msi — Deploy via Group Policy Software Installation or msiexec /i CirqueRMM.msi /quiet.
  • .bat — Right-click → Run as administrator. Downloads & installs silently via PowerShell (execution policy bypassed automatically).
  • .ps1 — For admins who want to inspect the script; run with powershell -ExecutionPolicy Bypass -File CirqueRMM-Install.ps1.

Site token is baked into all installers. Rebuild EXE/MSI after rotating the token (BAT & PS1 are generated dynamically).
