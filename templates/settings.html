Cirque RMM Agent

Deploy the Cirque RMM agent to Windows endpoints so technicians can open remote shell sessions directly from an asset's page.

Gateway URL: wss://rmm.corp.cirque.com
Quick-Deploy Steps
  1. Download the agent bundle below and extract it on the target Windows machine.
  2. Obtain an agent enrollment token from your administrator (one token per machine).
  3. Open an elevated PowerShell prompt and run:
    .\ install_service.ps1 -Token "<AGENT_TOKEN>"
  4. The installer registers and starts the CirqueRMM Windows service automatically.
Download Agent Bundle (.zip)
Token Management

Each endpoint needs a unique enrollment token. Generate tokens from the server:

python scripts/enroll_rmm_agent.py <HOSTNAME> [asset_id]
Tech API Key

Technicians need an API key with the rmm_connect permission to open remote sessions:

python scripts/create_api_key.py <username> rmm_connect
