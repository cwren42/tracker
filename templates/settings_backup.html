How it works
  1. Add a NAS Appliance with a local account.
  2. Create a Backup Policy linked to that NAS.
  3. Assign the policy to agents below.
  4. Backups run automatically; trigger manually from the asset page.

NAS folder layout:

\\NAS\Backups\
  └─ BRIAN-MSI\
       ├─ 2026-03-16\  ← FULL
       └─ 2026-03-17\  ← INCR

Use a local NAS account — never domain credentials.

Deploy agent

Backup is built into the RMM agent — no separate script needed. Update the agent on target machines to v2.5.8+ to enable backup support.

Trigger via the Backup tab on any asset page.
