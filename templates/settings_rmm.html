Silent mass deployment — users see nothing

The silent deploy script creates a hidden Windows Scheduled Task running as SYSTEM. No console window, no UAC prompt, no user dialog.

These options run a PowerShell download (irm … | iex) as SYSTEM. If Defender ASR blocks script-based installs in your environment, deploy the EXE (below) instead — and always pilot on one device before rolling out fleet-wide.
