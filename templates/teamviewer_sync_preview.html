What Happens Next
Update Process ({{ will_update|length }} assets):
  • Existing asset data will NOT be deleted or overwritten
  • TeamViewer ID will be added/updated
  • Online status will be updated
  • Last sync timestamp will be recorded
  • TeamViewer Connect link will be added - enables web-based remote control
  • Connect button will be enabled on asset page
Create Process ({{ will_create|length }} assets):
  • New assets created with auto-generated asset tags (TV-XXXXXXXX)
  • Category set to "Computer"
  • Status set to "In Use"
  • Only TeamViewer data populated (Name, TV ID, Status, Group as Location)
  • TeamViewer Connect link will be added - enables web-based remote control
  • No manufacturer, model, serial, or purchase info - you'll need to add these manually
  • Will appear in "Incomplete Assets" dashboard widget (needs to be added)
Data Safety:
  • No existing asset data will be deleted
  • Manual updates are always preserved
  • Sync only adds/updates TeamViewer-specific fields
